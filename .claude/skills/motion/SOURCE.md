# Origen

Skill "motion" del paquete npm `motion-ai@14.2.0` (MIT, Matt Perry / motion.dev,
https://github.com/motiondivision/ai-kit), copiada a mano desde `content/skills/motion`.

Auditoría (2026-10-25): solo Markdown, sin scripts ni binarios. El instalador `npx motion-ai` es interactivo
(requiere terminal) y además configura los servidores MCP remotos `https://mcp.motion.dev` y
`https://mcp.motion.dev/plus`; no se configuraron. Sin ellos funciona `best-practices/`; la búsqueda de docs,
los audits y el editor de transiciones necesitan el MCP (y parte, Motion+ pago).
